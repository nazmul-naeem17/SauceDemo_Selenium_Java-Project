# SauceDemo Automation Test
## Project Description
This project automates the login, add-to-cart, and logout flow for SauceDemo.com.

## Tech Stack
* **Language:** Java 11+
* **Library:** Selenium WebDriver 4.27.0
* **Framework:** TestNG
* **Build Tool:** Maven

## How to Run this Project
1.  **Clone** or Download this repository.
2.  **Import** the project into Eclipse (File > Import > Maven > Existing Maven Projects).
3.  Right-click `src/test/java/com/saucedemo/SauceDemoTest.java`.
4.  Select **Run As > TestNG Test**.
